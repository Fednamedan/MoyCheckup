# Мой чекап — Android-приложение

Дневник самочувствия: отмечаете на схеме тела, что болит, ведёте напоминания о таблетках, врачах и анализах,
в конце недели отправляете врачу PDF-сводку.

Дизайн «Ночное сияние»: тёмная тема со светящимся фоном-сиянием, стеклянные карточки, неоновая шкала боли.
Анимации: заставка с ЭКГ, кольцо самочувствия, пульсирующие зоны тела с бегущим сканером, шар силы боли, графики, конфетти.
Функции: индекс самочувствия, серия дней, советы, достижения, настроение, давление/пульс/температура/вес с графиками,
календарь боли, предупреждение при тяжёлых симптомах, PDF-сводка с показателями.

Kotlin + Jetpack Compose (Material 3). Минимальный Android: 8.0 (API 26).
Данные хранятся только на телефоне (SharedPreferences, JSON). Интернет не нужен.

## Как запустить

1. Установите Android Studio (Ladybug 2024.2 или новее). JDK 17 идёт в комплекте.
2. File → Open → выберите папку `MoyCheckup`.
3. Дождитесь Gradle Sync (первый раз скачает зависимости, нужен интернет).
4. Телефон: Настройки → О телефоне → 7 раз нажать «Номер сборки» → Для разработчиков → включить «Отладка по USB».
   Подключите телефон кабелем и разрешите отладку.
   Либо создайте эмулятор: Tools → Device Manager → Create Device.
5. Вверху выберите устройство и нажмите зелёный треугольник Run.

Готовый APK для установки: Build → Build Bundle(s) / APK(s) → Build APK(s).

## Что внутри

| Файл | Что делает |
|---|---|
| `ui/theme/Theme.kt` | Цвета, шкала боли, типографика, тёмная тема |
| `data/Body.kt` | Геометрия схемы тела (спереди и сзади) и попадание пальцем в зону |
| `ui/Components.kt` | Карточки, плашки боли, схема тела `BodyMap` |
| `ui/LogScreen.kt` | Экран «Что болит?»: тело, сила боли, ощущения, заметка, время |
| `ui/TodayScreen.kt`, `DiaryScreen.kt`, `PlansScreen.kt`, `HealthScreen.kt` | Четыре вкладки (Сегодня, Дневник, Планы, Здоровье) |
| `notify/Notifier.kt` | Уведомления по расписанию, кнопка «Принял», восстановление после перезагрузки |
| `report/PdfReport.kt` | PDF-сводка недели (PdfDocument) |
| `data/Repo.kt` | Хранение данных |
| `ui/Fx.kt`, `ui/Charts.kt` | Фон-сияние, заставка, кольцо, ЭКГ, конфетти, графики |
| `data/Insights.kt` | Индекс самочувствия, серия, советы, достижения |

## Уведомления

| Что | Когда приходит |
|---|---|
| Таблетка | За 30 минут: «Через 30 минут: название» и ровно в назначенное время: «Пора пить: название» с дозировкой и тем, как принимать. В уведомлении есть кнопка «Принял» |
| Врач, анализ | Накануне в 19:00 и в день визита за 2 часа до начала (не раньше 7:00) |
| Другое | В назначенное время |

Если таблетка уже отмечена как принятая, уведомление не показывается. Время уведомлений меняется в начале `notify/Notifier.kt`
(`PRE_MINUTES`, `EVE_HOUR`, `DAY_HOURS_BEFORE`, `DAY_EARLIEST_HOUR`).

## Что можно менять

- Цвета и шрифты: `ui/theme/Theme.kt`.
- Варианты описания боли (какая, когда, что ещё беспокоит, как давно, как принимать таблетки): списки в `ui/Util.kt`.
- Зоны тела и головы: `data/Body.kt`.
- Иконка приложения: `res/drawable/ic_launcher_foreground.xml`.

## Известные ограничения

- Проект написан без доступа к Android SDK и ни разу не собирался. Если Gradle Sync или сборка покажет ошибку,
  пришлите её текст, исправлю.
- Точные будильники на Android 14+ требуют разрешения «Будильники и напоминания»
  (Настройки → Приложения → Мой чекап). Без него уведомления могут приходить с задержкой в несколько минут.
- Данные не синхронизируются между устройствами и не копируются в облако.
